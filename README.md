# Live Watchlist

A responsive watchlist UI built with HTML, CSS and vanilla JavaScript.

## Features
- Prices for 8 symbols update every second from a simulated feed
- Gains and losses are color-coded
- Loading, error (with retry) and empty states
- Search filter and a canvas line chart of recent ticks
- Responsive layout for desktop and mobile

## Run it
Open index.html in any browser. No installation needed.

Note: prices are randomly generated for demonstration and are not real market data.
